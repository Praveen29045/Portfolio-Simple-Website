# Personal Portfolio Website

A simple personal portfolio website built with HTML and basic CSS. It includes a Home page that introduces my profile and a Contact page where visitors can find my contact details.

## Features

- Simple and clean design
- Home page with personal introduction
- Contact page
- Easy navigation between pages
- Built using HTML and CSS

## Technologies Used

- HTML
- CSS

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.

## Purpose

This project was created to practice basic HTML and CSS while building a simple online portfolio.# Portfolio-Simple-Website
